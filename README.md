🎧 AEMP PRO

Enjoy the sound.

AEMP PRO — музыкальный плеер, созданный Артёмом Еремеевым. Проект развивается с упором на удобство, оформление и комфортное прослушивание музыки.

✨ Возможности

- 🎵 Воспроизведение музыки
- 🎨 Настройка внешнего вида
- 🖌️ Встроенные скины интерфейса
- 🔊 Режим Mono
- 📂 Фонотека
- 🧡 Различные цветовые акценты

🚀 Версия 1.4

В обновлении AEMP PRO 1.4 добавлена система встроенных скинов:

- AEMP Classic
- AEMP Charm
- AEMP Bliss
- AEMP Aero

Теперь внешний вид плеера можно менять, выбирая подходящий стиль оформления.
